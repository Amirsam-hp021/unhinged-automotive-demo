# Unhinged Automotive — Website Redesign Demo

A design concept for [unhingedautomotive.com](https://www.unhingedautomotive.com): dark/light themes, quick search, filterable inventory, photo gallery, payment estimator, and a mobile call/text bar.

Single static page — open `index.html` or view it on GitHub Pages.

> Design demo only. Inventory data and photos were taken from the live site on Oct 31, 2026; the contact form does not send messages.
